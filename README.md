# Class 10 live sessions

Two in-class activities for a university marketing course, as static pages with no accounts and no backend of their own: phones post small JSON messages to a public [ntfy.sh](https://ntfy.sh) topic and the instructor's board reads them back live.

- `s1/` Mini brief vs outcome: teams submit one ad concept from one of two briefs; the class votes; the board reveals which brief made which.
- `s2/` Creative quality evaluation: everyone scores an ad on seven letters (0/1/2); the board shows the distribution per letter and reveals the expected score.

Open `index.html` for the instructor's checklist and key bindings. The room key lives in `config.js`.
